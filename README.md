# numeros-primos
CyberPrime Matrix

Aplicación web diseñada para la identificación de números primos mediante una interfaz con estética Cyberpunk y efectos visuales de lluvia digital estilo Matrix.

Funcionalidades

Validación de Primos: Algoritmo optimizado para determinar si un número entero es primo.

Fondo Dinámico: Lluvia de código Matrix renderizada en tiempo real mediante el elemento Canvas.

Estética Cyberpunk: Interfaz de usuario con colores neón (cian, magenta, amarillo), efectos de scanlines y glitch.

Sistema de Partículas:

Acierto (Primo): Explosión de partículas multicolor y neón.

Fallo (No Primo): Explosión de partículas rojas y efecto de glitch en el contenedor principal.

Tecnologías Utilizadas

HTML5: Estructura y contenedores de gráficos (Canvas).

CSS3: Estilos personalizados, variables de color neón y animaciones de glitch.

JavaScript: Lógica de validación matemática, manipulación del DOM y motores de renderizado para las animaciones de fondo y partículas.

Instalación y Uso

Guardar el código en un archivo llamado primo_checker.html.

Abrir el archivo en un navegador web moderno.

Ingresar un número en el campo >_VAL.

Hacer clic en ANALIZAR_NUCLEO para obtener el resultado.
